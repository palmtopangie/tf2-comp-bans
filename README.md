# tf2-comp-bans
[![Update Comp Bans](https://github.com/palmtopangie/tf2-comp-bans/actions/workflows/update-bans.yaml/badge.svg)](https://github.com/palmtopangie/tf2-comp-bans/actions/workflows/update-bans.yaml)

A generated list of cheating bans from [RGL](https://rgl.gg/Public/PlayerBanList) and [ETF2L](https://etf2l.org/etf2l/bans/). This ONLY includes bans for cheating, cheat distribution, cheat assistance, and cheat development. Files have been generated to be used with the [TF2 Bot Detector](https://github.com/surepy/tf2_bot_detector).  Bans automatically updated weekly.

Written in python, requires ``requests`` and `beautifulsoup4`.

### This repository serves as nothing other than a public repository containing an easily indexable list of bans from competitive Team Fortress 2 leagues. I hold no opinions on the banned users in this list, nor the reasons for their bans.
